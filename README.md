# مركز وائل حداد

موقع ثابت بالعربية والإنجليزية، مع نسخة عرض محلية وحزمة منفصلة للموقع العام. المصدر في `Source/`؛ لا يوجد build أو خادم خلفي للتطبيق.

## المعاينة

من جذر المستودع، باستخدام Python 3:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory Source
```

افتح `http://127.0.0.1:8765/`. ويمكن فتح `Source/index.html` مباشرة للمعاينة الأساسية. خطوط Google Fonts تحتاج اتصالاً؛ توجد خطوط بديلة من الجهاز.

## توليد التسليم

```sh
bash UPDATE-PACKAGE.command
```

يتطلب Bash وzip/unzip، وNode اختياري لفحص صياغة JavaScript. يُعاد توليد Demo وملفات ZIP محلياً، وهي مستثناة من Git. أمر التغليف يخفي الملفات الداخلية في Finder ويُبقي مجلد التسليم وZIP الكامل ظاهرين؛ لإظهار المخفي استخدم Cmd+Shift+.

المصدر يبقى `mode: 'demo',`، والحزمة المخصصة للرفع تستخدم `live`. الحجز يجهّز رسالة WhatsApp، ويحتاج المستخدم إرسالها من المحادثة. بيانات لوحة التحكم والتتبّع وتقارير الفحص أمثلة محلية؛ لا توجد إدارة حقيقية أو مصادقة أو قاعدة بيانات خلفية.

## النشر على GitHub Pages

ملف `.github/workflows/pages.yml` يبني نسخة `live` وينشرها تلقائياً عند push إلى `main`، ويمكن تشغيله يدوياً من Actions. مصدر Pages في إعدادات المستودع هو **GitHub Actions**. لا ينشر لوحة العرض أو مسارات الإدارة التجريبية، ولا يغيّر `Source/data.js` عن `demo`.

لإنشاء ملفات النشر محلياً: `bash Source/tools/build-pages.sh`، وتكون داخل `.pages-output/`. السكربت يشغّل التغليف نفسه ثم يفك حزمة الرفع المولّدة؛ لا توجد شيفرة موقع مكررة للصيانة. المسارات النسبية تدعم عنوان موقع المشروع تحت اسم المستودع.

راجع [دليل الصيانة](Source/MAINTENANCE-AR.md) قبل التعديل. مصادر الشعارات موثقة؛ وجود الأصول هنا ليس ادعاءً بترخيص تجاري أو وكالة أو اعتماد من الماركات.
