# فحوص الموقع

الموقع نفسه HTML وCSS وJavaScript عادي، ويعمل دون تثبيت أو بناء. هذا المجلد مستقل، لتشغيل فحوص المتصفح فقط. يحتاج Node.js بإصدار 20 أو أحدث وnpm.

من جذر المشروع:

```sh
cd Source/tests
npm install
npx playwright install chromium
npm run serve
```

أبقِ نافذة السيرفر مفتوحة؛ يقدّم محتويات `Source/` على `http://127.0.0.1:8765/`. افتح نافذة طرفية ثانية داخل `Source/tests` وشغّل:

```sh
npm test
```

لتشغيل مجموعة واحدة:

```sh
npm run test:smoke
npm run test:flows
npm run test:hero
npm run test:hood
```

- `smoke.mjs`: عددها 88 حالة؛ 11 مساراً بالعربي والإنجليزي، 390×664 و1366×768، فاتح وغامق. تفحص أخطاء الصفحة والكونسول والتجاوز الأفقي وتحفظ لقطات كاملة.
- `flows.mjs`: الفحوص الوظيفية الـ22: الحجز ورابط واتساب، عدم استبدال زر الحجز أثناء الكتابة، الأرقام العربية، الحجوزات ولوحة التحكم، رفع صورة الفحص، اختيار القطعة والموافقة، حالة السيارة، إخفاء العرض وإعادة البيانات، الإنجليزية والتخزين المقفول.
- `hero.mjs`: ظهور النص ولمعته وعدم تكرارهما، انتظار فك الفيديو، تجمد إطاره النهائي، عدم إعادة التشغيل عند تغيير اللغة أو فتح القائمة والرجوع من الحجز، تقليل الحركة، تحميل الشعارات بألوانها وترتيبها، وبقاء العنوان والحجز والسيارة في أول شاشة. يتحقق من الحجم الكبير للسيارة على الكمبيوتر1366px، وملاءمة الموبايل، وتحميل الأرضية ومحاذاتها للإطار. يتضمن صف الماركات عند320 و768px.
- `hood.mjs`: تطابق أول إطارCanvasمع الجسم الأصلي وخلية الغطاء والمحرك، وشفافية الخلفية، واختلاف الفتح والإغلاق، ومطابقة النهاية للصورة البديلة. يقارن بكسلات الغطاء المفتوح والمتحرك والمغلق والمحرك بأطلس الفيديو المرجعي، دون اشتراط وجود المصابيح أو الشبك داخل أطلس الحركة. يفحص جميع الخلايا0..46مقابل صورة الجسم الأصلية في المصابيح والرفرف والصدام والسقف والزجاج والباب والخلف وحدوده الخارجية، مع تطابقRGBوalphaتماماً خارج مسار الغطاء. يقارن المناطق نفسها خلال التشغيل الفعلي في وضعيات وسيطة من الأطالس الأربعة، إضافة إلى ثبات العجلات والباب وتجميد النهاية وإطار العرض والأرضية ومهلة300ms. يغطي تأخير فك الفيديو أو القاعدة، والفشل والتلف وغياب أطلس أو إحدى طبقتي الضوء ورفض التشغيل التلقائي، وإلغاء التشغيل عند التنقل أو تبديل اللغة وتقليل الحركة. الفيديو ساعة تشغيل فقط.

يفحص أيضاً ظهور دخان شفاف أثناء الإغلاق وخلو طبقته عند البداية والنهاية وتقليل الحركة. تبقى مقارنة بكسلات السيارة مستقلة عن طبقة الدخان حتى لا يخفي المؤثر تغير الجسم أو اختلاف الصورة النهائية.

في إصدار `20261025-original-body` تتحقق عينات الرسم الفعلية من ثبات الإطار المغلق46خلال المراحل الثلاث، ثم مرحلةLEDعند2.15s، ثم المصابيح الرئيسية عند2.85s، وانتهاء الساعة3.5s. تقارن سطوع شرائطLEDوعدستي المصابيح بين المراحل: تضيء الشرائط وحدها في الوسط وتبقى العدستان داكنتين حتى المرحلة الأخيرة. تقارن جميع بكسلاتalphaبالمساواة التامة بين الإغلاق الداكن وLEDوالمصابيح، وتطلب ثباتRGBخارج منطقة المصابيح والتوهج المحدود(34،225)..(628،502)، وثبات السقف وقاعدة الزجاج والزجاج والعجلات والباب داخل مناطق مستقلة. بذلك يُكشف تبديل وضعية السيارة عند الإضاءة حتى لو بقي عنصرCanvasمكانه. تشمل فحوص تقليل الحركة ومنع إعادة التنزيل طبقتي الضوء، ويغطي غياب كل طبقة العودة للصورة النهائية. يظل سطح الشبك وشاراته من الصورة الأصلية، مع توهج المصابيح النهائي؛ مقارنة منطقة التفاصيل تسبق هذا التوهج.


شغّل الفحوص على نسخة `Source/` بوضع `demo`. تفتح متصفحات جديدة ببيانات معزولة؛ لا تنقر زر واتساب ولا ترسل أي رسالة. صورة الرفع التجريبية تُنشأ في مجلد مؤقت للنظام وتُحذف بعد انتهاء الفحص. الخطوط الخارجية تحتاج اتصالاً بالإنترنت؛ أخطاء تحميلها تظهر ضمن النتائج.

النتائج ولقطات الشاشة في `Source/tests/results/`، وهو مجلد مستثنى من Git. تُرجع الفحوص رمز خروج غير صفري عند فشل أي تحقق أو ظهور أخطاء صفحة أو كونسول. كل مجموعة تحفظ `results.json` حتى عند تعذر إكمال التشغيل.

يمكن تغيير الرابط ومجلد النتائج لكل المجموعات بالمتغيرين `TEST_BASE_URL` و`TEST_RESULTS_DIR`، أو تمريرهما بهذا الترتيب عند تشغيل ملف مباشرة:

```sh
node hero.mjs http://127.0.0.1:9000/ ./results-preview
```

يُفسر مسار النتائج النسبي من مجلد العمل الحالي، وتنشئ كل مجموعة مجلداً خاصاً بها داخله. لتغيير منفذ السيرفر استخدم متغير `PORT` واضبط `TEST_BASE_URL` أو الرابط الممرّر للاختبارات على المنفذ نفسه.

يستخدم التشغيل Chromium الذي ثُبّت بالأمر أعلاه. لاستخدام متصفح Chromium مثبت مسبقاً، عيّن `PW_CHROMIUM_EXECUTABLE_PATH` إلى ملفه التنفيذي؛ لا توجد مسارات جهاز ثابتة داخل الفحوص.

تقارن الفحوص إطاراتCanvasبتركيب القاعدة مع خلايا الأطالس والصورة النهائية، وتتحقق من ثبات العجلات والباب وأبعاد عنصر العرض. مقارنة أجزاء الجسم الثابتة بصورتها الأصلية مستقلة عن أقنعة التحضير وأطالس التشغيل، ولا تعتمد على قراءة اسم الشارة آلياً. مناطقها خارج المساحة الكاملة التي يشغلها الغطاء أثناء حركته؛ لا تُستثنى المصابيح والصدام لمجرد قربها من الغطاء. مقارنة الغطاء والمحرك بأطلس المرجع تتحقق من حفظ التفاصيل المصورة، لكنها لا تثبت وحدها واقعية اتصال المفصلات أو صحة شكل الجسم. عند تعديل الوسائط راجع تسع وضعيات بصرياً للتأكد من اتصال الغطاء بحجرة المحرك وقاعدة الزجاج والرفارف، وعدم قطع العجلات أو ظهور حدود مزج أو قفزة منظور؛ وتحقق من بقاء النهاية مجمدة وتفاصيل الشعارات الأصلية. قارن الجسم كله بصورة الاستوديو الأولى الواضحة: أذرع الجنوط، تجاويف الإطارات، حدود المصابيح والصدام والخلف، وانسياب الباب والزجاج. لا يثبت ثبات البكسلات وحده صحة صورة تحضير مشوهة؛ يجب أن يبقى الجسم من الأصل بتحويل منظور عام واحد دون تدفق بصري أو شد موضعي. على الكمبيوتر قارن حجم السيارة والأرضية العاكسة بالصورة القديمة، وتحقق من بقاء الأرضية أسفل العجلات دون قص أو مستطيل ظاهر.

راجع الدخان بصرياً أثناء الحركة على الموبايل والكمبيوتر: يبدأ من المحرك ويرتفع دون حافة مستطيلة أو قطع علوي، ويبقى خفيفاً ولا يحجب النصوص والشعارات، ثم يتلاشى قبل مرحلةLED. راجع قفل الغطاء قبل الإضاءة، ووضوح مرحلة الشرائط وحدها قبل تشغيل المصابيح الرئيسية. الدخان مرسوم محلياً بالكود، وليس جزءاً مقتطعاً من الفيديو.
